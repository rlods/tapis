# Tapis

Downloads and the update feed for **Tapis**, a cloth rug that lies on your Mac desktop.
Website: [rlods.github.io/tapis](https://rlods.github.io/tapis/).

[![Tapis: the 30-second film](assets/film-poster.jpg)](https://rlods.github.io/tapis/assets/film.mp4)

*Thirty seconds of the real cloth at work: hide the mess, reveal a masterpiece, roll it up and carry it away. Click to play.*

- **Download:** the latest DMG is on the [Releases](https://github.com/rlods/tapis/releases/latest) page.
- **Updates:** Tapis checks `https://rlods.github.io/tapis/appcast.xml` (Sparkle) and updates itself.

The source code is not in this repository.

## Inspiration

The idea comes from [a tweet by Terkel](https://x.com/terkelg/status/2107541877176094880): a fun idea, and just as much fun to build. Thank you!
