Tapis

为你的 Mac 桌面铺上真实的地毯，挂上真实的窗帘。

Tapis 在你的桌面上铺一张柔软的布料模拟地毯，位于图标之上、所有窗口之下。抓住一角就能把它折起来，也可以把它卷起来，或者把东西扫到它下面。你还可以从菜单栏挂下窗帘，拉过整个桌面。

下载 Mac 版 免费 · macOS 14 或更高版本 · Apple 芯片

现在你看得见，现在你看不见。

就像真正的织物

折叠和卷起

抓住任意位置并拖移，即可掀起、折叠或卷起地毯。把折痕拖回去即可撤销，或者连按将整张地毯抚平。

覆盖在图标上

每个桌面图标都会在地毯下顶起一个小鼓包。图标堆得越多，鼓包就越大。

自己动手设计

波斯、赫里兹、基里姆、柏柏尔、条纹、镶边、沙滩巾、门垫或长绒图案任你挑选，颜色、流苏、磨损和绒毛长度也都由你决定。

叠放多张地毯

地毯可以相互叠放，你移动的那张会滑到最上面。

还有窗帘

从菜单栏挂下窗帘。沿着菜单栏滑动它们，拉开或合上，轻轻一甩，它们又会垂回原来的褶皱。丝绒、亚麻、条纹、镶边，或者用你自己的图片。

多种布置

为每种心情准备一套地毯或窗帘，一套用于工作，一套用于周末，在菜单栏中点按一下即可切换。

🔈织物声音。移动时会发出柔和低沉的羊毛摩擦声，折痕落下时会有轻轻的一声闷响。点按一下即可关闭。

🍃对 Mac 很轻量。静止的地毯几乎不占用 CPU。即使整天待在桌面上，也不会让风扇狂转，不会消耗电池。

支持 Tapis

Tapis 是免费的。如果它让你的桌面变得温馨了一点，你可以在 Ko-fi 上请我喝杯咖啡，或在 GitHub 上赞助。

使用方法

一切操作都只需用鼠标在地毯上完成。

  1. 折叠

    抓住地毯的任意位置并拖移，即可掀起、折叠或卷起它。折痕会停留在你放下的位置。

    把折痕拖回去即可撤销。连按可将整张地毯抚平。

  2. 按住以编辑

    在地毯上按住半秒：地毯即被选中，编辑时不会被折起。

    拖移可移动地毯，拖移一角可调整大小，拖移顶部的旋钮可旋转（按住 ⇧ 键以 15° 为单位对齐）。完成后再次点按地毯，或点按其他任意位置。

  3. 打造专属于你的地毯

    选中的地毯下方会出现一个小工具栏。点按设计可调整图案、颜色、流苏、磨损和绒毛长度。

    工具栏还可以将地毯旋转 90°、抚平或移除。

  4. 滑到图标下方

    默认情况下，地毯铺在桌面图标上方，图标会在地毯下顶起鼓包。地毯也可以铺在图标下方，就像垫在文件下的一块垫子。

    在工具栏中选择放在图标下方。要再次操作这张地毯，请在菜单中选取重新摆放地毯。

  5. 添加更多地毯

    在菜单中选取添加地毯（⌘N）。地毯会相互叠放，你移动的那张会滑到最上面。

    取消勾选显示地毯，可暂时让桌面恢复整洁。

  6. 挂上窗帘

    在菜单中选取窗帘：一幅窗帘便会从菜单栏垂挂下来。横向拖移可让它沿菜单栏滑动，拖向另一幅窗帘则会把那幅推开。

    按住 ⌘ 连按可拉开或合上窗帘，连按则可将其抚平。按住窗帘后，可拖移两侧的控制柄调整大小。添加窗帘可再挂一幅。

  7. 切换布置

    一个布置就是一套地毯或一套窗帘。一套用于工作，一套用于周末，在菜单中点按一下即可切换。

    管理布置…可用于创建、复制、重新命名和删除布置。所有更改都会自动存储。

安装

免费。需要配备 Apple 芯片的 Mac，以及 macOS 14 或更高版本。

  1. 下载

    从发布页面获取最新的 DMG。

  2. 拖到“应用程序”文件夹

    打开 DMG，将 Tapis 拖到“应用程序”文件夹中。

  3. 启动

    从“应用程序”文件夹中打开 Tapis，它的图标会出现在菜单栏中。

  4. 保持最新

    有新版本时，Tapis 会通知你并提供更新。

隐私从设计之初就已考虑

无需帐户，没有数据分析。唯一的网络请求是检查更新，而且不会发送任何关于你的信息。是否更新始终由你决定。Tapis 完全在你的 Mac 上运行，你的地毯和窗帘永远不会离开它。

🏠

存储在你的 Mac 上

你的地毯、窗帘、设计和布置只保存在你的 Mac 上，不会同步，也不会上传。

🗂

你的桌面始终属于你

Tapis 会向访达询问图标的位置，只为让地毯覆盖在图标上。这些信息永远不会离开你的 Mac。

🔄

只为检查更新

为了确认是否有新版本，Tapis 会读取 GitHub 上的一份公开列表。它不会发送任何关于你或你的 Mac 的信息。

灵感来源

Tapis 的灵感来自 Terkel 的一条推文。这个点子非常有趣，而把它做出来的过程也同样有趣。
